# TP14-GestorJuegos
## Retro Arcade Store
Tienda web de juegos clásicos hecha con HTML, CSS y Bootstrap 5 (por CDN) con tema oscuro.

**Incluye:** barra de navegación, tarjetas de juegos, tabla de ranking, diseño responsivo (grid de Bootstrap) y una tarjeta de **Juego Destacado** con un botón que abre mi videojuego, publicado en GitHub Pages.

**Archivos:** `index.html` y `style.css`.
